# cakecake-rs v0.4.0 — 直播间播放器重做、创作中心可用了

真机（vivo V2180GA / Android 11）逐项验过。这一版主要是把「直播间」和「创作中心」两条链路
从能用做到可以日常使用，同时修掉一批 Android 输入法/窗口的坑。

## 1. 直播间播放器：和视频详情页同一套

- 竖屏：控件蒙层（点画面出现、3 秒自动隐藏）—— 播放/暂停、`● 直播中 时长`、**清晰度**、
  **弹幕开关**、全屏；UP 主信息（头像/昵称/人气/开播时间）挪到**页面最上方一条**，
  点头像进主播主页。
- 横屏全屏：转屏 + 沉浸式，16:9 居中不拉伸；底部居中是**平时隐藏的输入框**，
  点画面才出现，可输入可发送。
- **聊天即弹幕**：聊天消息从画面右侧飘过（9 秒一条，系统提示不飘），登录后发出去的消息
  竖屏聊天列表和横屏弹幕是同一份数据。
- 标题不再单占一块版面，改成聊天里的系统提示（`直播间：xxx`）；明文 HLS 地址不再显示。

## 2. 直播清晰度（需要服务端配合）

SRS 加了一路 480p 转码（`deploy/srs-docker.conf`），后端 `on_publish` 接受转码变体
`<key>_sd`（`internal/handler/live.go`）。客户端探测到 `_sd.m3u8` 才露出「流畅」档，
点一下即切，探不到就只有「原画」（不做假选项）。

## 3. 创作中心：文章能发、草稿能存、能编辑

| 问题 | 根因 | 处理 |
|---|---|---|
| 点「发布」其实只存了草稿，随后跳详情 404 | 客户端没传 `publish`，后端默认 false | 拆成 **发布 / 存草稿**，分别传 `publish` |
| 发布报「参数错误」 | 后端要求发布时标题+正文都非空 | 客户端同规则先校验并给出人话提示 |
| 存完草稿列表里看不到 | 列表接口默认不列草稿 | 显式请求 `status=all`（后端补上该语义） |
| 预览草稿 404 | `GET /articles/:id` 只放行已发布 | 允许**作者本人**读自己未发布的文章 |
| 列表「两个删除、没有编辑」 | 行尾写删除但点击是编辑，下面又一条删除 | 每行右侧 **编辑 / 删除** 两个动作 + 状态（草稿/审核中/未通过） |
| 文章编辑器只能输入数字 | NativeActivity 没有输入连接，egui TextEdit 收不到中文 | 所有输入框改为「自绘 + 隐藏 EditText 托管」，Java 壳新增多行模式 |

发布成功会弹轻提示并自动进文章详情当预览；开审核时提示「已提交，审核通过后公开」。

## 4. 其它

- 视频投稿调用**系统文件选择器**（不再只能 adb push 到 inbox），选中后显示**首帧缩略图 + 时长**。
- 点赞/收藏/关注/投币/评论这类需要登录的操作，**直接弹登录窗**（不再在角落写「先去登录」）；
  登录态落盘，重装/重启不用再登。
- 评论：文字在上、图片在下，**点图放大查看**（全屏按原始比例居中，点任意位置关闭）。
- 时长是小数（`34.924533`）时整条详情解析失败的问题修掉了。
- 系统栏内衬改用真实 `WindowInsets`：状态栏/导航栏被隐藏时不再凭空留一条黑边；
  横屏时控件按导航栏实际宽度让位。

## 已知限制

- 横屏输入依赖 `SHOW_FORCED` + `NO_EXTRACT_UI`，个别 ROM 仍可能把键盘放到屏幕外；
- HLS 仍是 3 秒切片，端到端延迟 6~9 秒；
- 文章编辑器暂不支持插图与字号（Web 端有），Markdown 文本仍可直接粘贴。
