# cakecake-rs v0.3.1 — 直播改走同局域网、修好直播间聊天

真机（vivo V2180GA / Android 11）实测：**直播不再卡在「缓冲中…」，画面正常且方向正确，聊天能发出去、对端能收到。**

## 1. 直播一直缓冲：根因是媒体地址落到了 `127.0.0.1`

旧逻辑里播放地址是 `http://<API 主机>:8000/live/<stream_key>.m3u8`。真机上 API 走
`adb reverse` 时 base 就是 `127.0.0.1:8080`，于是媒体地址也变成 `127.0.0.1:8000` ——
**这个地址在手机上指向手机自己**，MediaPlayer 连得上却永远等不到数据，表现就是一直转圈。

现在的顺序（`api.rs`）：

1. `CAKECAKE_MEDIA_BASE`（自建 SRS 不在 8000 端口时的显式覆盖）；
2. 之前探测成功并缓存的媒体源；
3. API 主机的 `:8000`（API 非回环时最可信）；
4. 打包时烘焙 / 运行期指定的局域网地址（`CAKECAKE_LAN_API`）；
5. 最后才是 API 主机兜底（错误信息里能看到到底试过哪些）。

进直播间时**先探一遍 m3u8**（要求真的返回 `#EXTM3U`），拿到播放列表才创建 MediaPlayer；
探不到就直接在播放区列出「试过哪些地址」，点一下重试，不再无限缓冲。

## 2. 同局域网优先：API / WS / 媒体统一走电脑的 LAN IP

启动时（第 2 帧，后台线程）按优先级并发探测候选地址，选**优先级最高且真的通**的那个：

```
局域网（打包烘焙） > 设置页保存的 > 当前 > 127.0.0.1（USB） > 10.0.2.2（模拟器）
```

- 选中的是回环地址时，会再用本机 /24 网段扫一遍 `:8080/api/v1/health`；
  扫到电脑就直接换成 `http://192.168.x.x:8080` 并写进 `server.txt`（下次直接命中）。
  这样**换了 Wi-Fi / 电脑换了 IP 也能自己找回来**，不需要 `adb reverse`、也不用重新打包。
- 自动切地址不再清空登录态（token 在内存里，清掉就得重新登录；换的若是另一台后端，
  接口会返回 40100 走刷新失败流程）。
- 设置页「服务器」下方显示当前后端 + 直播源，并提供「自动查找电脑」按钮。

实测产物：`server.txt` 从 `http://127.0.0.1:8080` 自动变成 `http://192.168.1.10:8080`，
直播间信息行显示 `HLS http://192.168.1.10:8000/live/4d5e….m3u8`。

## 3. 画面上下颠倒：OES 纹理别自己再翻一次

`video.rs` 的顶点着色器原来写 `v_uv = vec2(a_pos.x, 1.0 - a_pos.y)`，而
`SurfaceTexture.getTransformMatrix()` 已经把设备需要的翻转算进去了，等于翻了两次。
现在 `v_uv = a_pos`，只依赖变换矩阵；直播画面方向正确（视频详情页同一条链路一并修好）。

## 4. 直播间聊天发不出去

三处问题：

| 问题 | 原因 | 修复 |
|---|---|---|
| 打字进不了输入框 | 安卓 NativeActivity 的窗口没有输入连接，`egui::TextEdit` 收不到中文（软键盘只会吐数字键），`chat.input` 一直是空的，`chat_send()` 直接 return | 聊天输入改成和评论/弹幕同一套：Java 壳里那个隐藏 `EditText` 当输入法宿主，`chat_sync_ime()` 每帧把内容镜像回来，输入框自己画 |
| 发出的消息「没反应」 | 只有服务器广播回来才显示，弱网下要等好几秒 | 本地立即回显；服务器回显同一句时按 `pending` 去重（用 `user_info` 回传的昵称判断是不是自己） |
| 断线后彻底发不出去 | 连接一断只留一句「连接失败」，没有重连 | 退避自动重连（1/2/4/8 秒）+ 头部「重连」按钮，输入框不禁用 |

另外：

- 键盘右下角现在是「发送」：Java 壳加了 `OnEditorActionListener`，
  `video::ime_action()` 每帧取一次，按了就直接发（不用再去点按钮）；
- 发送后清空原生输入框，并挡住「清空还没生效就把刚发的那句又镜像回来」的回显抖动；
- 服务端 120 秒读超时用 25 秒一次 WS ping 保活（上一版已加，这一版连同后端
  `SetPingHandler/SetPongHandler` 一起验证）。

## 已知限制

- 局域网扫描只在**启动时**做一次；电脑比 App 后开的话，用设置页「自动查找电脑」或重进 App；
- HLS 仍是 4 秒切片、端到端延迟 6~9 秒（要 1 秒级得换 HTTP-FLV + 软解）；
- 扫描依赖手机当前 Wi-Fi 所在 /24 网段，跨网段（路由器做了隔离）时仍需手填地址。
